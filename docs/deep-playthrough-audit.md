# 深度体验审查规格

## 背景

中文版不只是把首屏翻成中文，还需要在手机和桌面上完整跑通反物质维度的主要流程。此前审查主要覆盖新存档、无限、永恒和现实阶段，且偏桌面宽度；手机端的底栏遮挡、时间研究树、天体后期页面和终局页面容易漏掉。

## 游戏阶段

审查按游戏自身重置层构造状态：

1. 新存档：反物质维度、成就、统计、选项、商店。
2. 无限阶段：无限点数、突破无限、无限维度、复制品、挑战。
3. 永恒阶段：永恒点数、时间维度、时间研究、永恒挑战。
4. 时间膨胀阶段：时间膨胀、快子粒子、膨胀升级。
5. 现实阶段：现实机器、符文、特权、黑洞、现实升级。
6. 天体阶段：Teresa、Effarig、无名之辈、V、Ra、Lai'tela。
7. Pelle 终局阶段：末日、遗迹、裂隙、Pelle 升级和星系生成器。

## 审查方法

`npm run audit:deep` 会启动 `dist/` 静态服务，用 Playwright 真实浏览器执行以下动作：

1. 分别打开手机视口 `390×844` 和桌面视口 `1440×960`。
2. 清空本地存档并重置游戏。
3. 通过游戏对象构造每个阶段的资源、解锁位和重置层状态。
4. 遍历所有 Tab/Subtab，强制显示页面并等待 Vue 更新。
5. 检查可见文本中的候选英文残留。
6. 检查文档级横向溢出和可交互元素左右越界。
7. 在手机视口检查底部导航是否遮挡可交互内容。
8. 记录页面运行错误，并对手机端有问题的页面截图。

## 验收标准

1. 手机和桌面视口都不能出现页面运行错误。
2. 普通 UI 不应出现候选英文残留；允许保留 GitHub、Gist、iOS、AM、IP、EP、RM、STD、Teresa、Effarig、Ra、Pelle 等名词或缩写。
3. 手机端不应出现文档级横向滚动。
4. 手机端首屏和滚动到底部时，可交互按钮不得被底部导航遮挡。
5. 复杂图形页面可以有内部滚动或缩放，但不能把整个文档撑成桌面宽度。

## 修复流程

1. 先运行 `npm run build:chinese`，确保 `dist/` 是当前源码。
2. 运行 `npm run audit:deep`，阅读 `docs/deep-playthrough-audit.md` 中的问题分组。
3. 优先修复手机端遮挡、横向溢出和整段英文残留。
4. 修复后重新构建并重复审查，直到深度审查、移动端回归和 E2E 回归全部通过。
