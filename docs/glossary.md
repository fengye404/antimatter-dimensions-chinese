# 游戏术语中英对照表

## 核心资源与货币

| 英文 | 中文 | 备注 |
|------|------|------|
| Antimatter | 反物质 | 游戏主要货币，通过维度生产获得 |
| Infinity Points (IP) | 无限点 | 第一次重置后获得，通过反物质数量换算 |
| Eternity Points (EP) | 永恒点 | 第一次永恒后获得，通过无限点数换算 |
| Time Theorems (TT) | 时间定理 | 用于购买时间研究的资源 |
| Time Shards | 时间碎片 | 时间维度产生，用于获得额外的时间间隔升级 |
| Reality Machines | 现实机器 | 现实层获得的资源 |
| Dilated Time | 膨胀时间 | 时间膨胀相关的高级资源 |
| Replicanti | 复制品 | 自主增长的资源，可生成复制品星系 |

## 维度系统

| 英文 | 中文 | 备注 |
|------|------|------|
| Antimatter Dimension | 反物质维度 | 共8层，第1层产生反物质，逐层递推 |
| 1st-8th Antimatter Dimension | 第1-8反物质维度 | 按层级命名 |
| Infinity Dimension | 无限维度 | 在达到无限后解锁，共8层 |
| 1st-8th Infinity Dimension | 第1-8无限维度 | 在无限时不重置 |
| Time Dimension | 时间维度 | 第一次永恒后解锁，共8层 |
| 1st-8th Time Dimension | 第1-8时间维度 | 在永恒时重置 |

## 重置机制与层级

| 英文 | 中文 | 备注 |
|------|------|------|
| Dimension Boost | 维度提升 | 低级重置，获得方式：购买80个第8维度 |
| Antimatter Galaxy | 反物质星系 | 中级重置，初始需80个第8维度，后续增加60个 |
| Crunch / Infinity | 坍缩/无限 | 高级重置，达到1.80e308反物质时触发 |
| Eternity | 永恒 | 超级重置，达到1.80e308无限点时触发 |
| Reality | 现实 | 最终重置，需要大量现实机器 |
| Dimensional Sacrifice | 维度牺牲 | 特殊收益机制，用第1维度乘积计算加成 |
| Replicanti Galaxy | 复制品星系 | 通过复制品达到1e30000获得的免费星系 |

## 升级与研究

| 英文 | 中文 | 备注 |
|------|------|------|
| Tickspeed | 时间间隔 / 每秒游戏刻数 | 机制名按语境译为“时间间隔”；解释读数时译为“每秒游戏刻数” |
| Tickspeed Upgrade | 时间间隔升级 | 缩短游戏刻间隔，使维度生产更快；按钮可写“时间间隔花费” |
| Infinity Upgrade | 无限升级 | 用无限点购买，在无限时重置 |
| Eternity Upgrade | 永恒升级 | 用永恒点购买，在永恒时保留 |
| Time Study | 时间研究 | 可重新分配的技能树升级 |
| Eternity Milestone | 永恒里程碑 | 达到永恒次数解锁，永久效果 |
| Perk | 特权/津贴 | 用特权点购买，永恒后获得 |
| Reality Upgrade | 现实升级 | 用现实机器购买的高级升级 |

## 数值单位

| 英文 | 中文 | 备注 |
|------|------|------|
| e/E notation | 科学计数法 | 如 1e100 表示 10^100 |
| Tick/s | 游戏刻/秒 | 游戏速度单位，UI 中可写“次/秒” |
| per second | 每秒 | 生产速率单位 |
| multiplier | 倍数 | 计算中的乘数概念 |
| boost | 提升 | 加成或强化 |
