# 移动端 UI 适配设计

## 背景

中文版计划以 PWA 或 WKWebView 形式在手机上运行。原版现代界面是桌面优先布局：左侧固定导航、宽维度行、顶部信息区横向展开；在手机浏览器里如果缺少 viewport，会被整页缩放成不可点击的桌面截图。

## 目标

1. 手机宽度下不再缩放桌面页面，而是使用真实设备宽度渲染。
2. 现代界面的左侧导航在窄屏下改为底部浮动导航，主资源信息回到顶部 HUD，底栏只承担主 Tab 切换。
3. 当前主 Tab 的子 Tab 在底部导航上方横向展示，避免依赖鼠标 hover。
4. 反物质维度首屏改为手机游戏式三列紧凑行：维度名称、数量、购买按钮并排展示，避免卡片过高。
5. 手机端使用浏览器页面原生滚动，避免 iOS Safari 内层滚动容器不跟手。
6. 保留桌面端布局，不影响原有键鼠体验。

## 实现

1. `public/index.html` 添加 `viewport-fit=cover`、主题色和 iOS PWA 状态栏 meta。
2. `public/stylesheets/new-ui-styles.css` 增加移动端媒体查询：
   - `max-width: 700px` 或粗指针窄屏设备启用。
   - `.c-modern-sidebar` 从左侧栏改为底部浮动导航，隐藏侧栏资源卡，降低底栏高度。
   - 当前 Tab 的 `.subtabs` 固定在底部导航上方，触屏可横向滚动。
   - `html` / `body` 在手机端恢复纵向滚动，`.game-container` 不再作为内层滚动容器。
   - `.game-container` 底部保留安全区和导航空间，防止底部内容被固定导航遮住。
   - 反物质维度行改为三列 grid，维度名称/倍率、拥有数量、购买按钮在一行内扫读。
   - 未解锁计时器速度区域在移动端不再占隐藏高度，避免首屏出现空白断层。
   - 早期推进按钮必须完整位于底部导航上方，底栏可以覆盖非交互性的进度条尾部，但不能遮挡维度提升或反物质星系按钮。

## 验收

1. iPhone 级宽度下 `.c-modern-sidebar` 位于底部，宽度接近视口宽度并位于安全区之上。
2. 主游戏容器不再被侧栏挤压，左边距为 0。
3. 维度行至少使用三列布局，购买按钮在视口内，不出现横向滚动。
4. 顶部信息区、玩法按钮、保存计时器不与底部导航重叠，早期重置按钮完整可点击。
5. 手机端向下滑动时 `window.scrollY` 会变化，页面使用原生滚动链路。
6. 桌面端原现代界面不改变侧边栏布局。
