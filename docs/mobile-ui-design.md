# 移动端 UI 适配设计

## 背景

中文版计划以 PWA 或 WKWebView 形式在手机上运行。原版现代界面是桌面优先布局：左侧固定导航、宽维度行、顶部信息区横向展开；在手机浏览器里如果缺少 viewport，会被整页缩放成不可点击的桌面截图。

## 目标

1. 手机宽度下不再缩放桌面页面，而是使用真实设备宽度渲染。
2. 现代界面的左侧导航在窄屏下改为底部导航，保留资源显示和主 Tab 切换。
3. 当前主 Tab 的子 Tab 在底部导航上方横向展示，避免依赖鼠标 hover。
4. 反物质维度首屏改为单列卡片式布局，按钮宽度随屏幕收缩。
5. 保留桌面端布局，不影响原有键鼠体验。

## 实现

1. `public/index.html` 添加 `viewport-fit=cover`、主题色和 iOS PWA 状态栏 meta。
2. `public/stylesheets/new-ui-styles.css` 增加移动端媒体查询：
   - `max-width: 700px` 或粗指针窄屏设备启用。
   - `.c-modern-sidebar` 从左侧栏改为底部横向滚动导航。
   - 当前 Tab 的 `.subtabs` 固定在底部导航上方，触屏可横向滚动。
   - `.game-container` 占满视口，底部保留安全区和导航空间。
   - 反物质维度行改为单列，维度名称/数量/购买按钮上下排列。

## 验收

1. iPhone 级宽度下 `.c-modern-sidebar` 位于底部，宽度等于视口宽度。
2. 主游戏容器不再被侧栏挤压，左边距为 0。
3. 维度购买按钮在视口内，不出现横向滚动。
4. 顶部信息区、玩法按钮、保存计时器不与底部导航重叠。
5. 桌面端原现代界面不改变侧边栏布局。
